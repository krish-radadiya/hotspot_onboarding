# Hotspot Onboarding Assignment

## Overview
This project implements the Flutter onboarding questionnaire for Hotspot Hosts.

## Features Implemented
- Experience Selection screen with animated cards and comment box
- Onboarding Question screen with text, audio, and video recording
- Fully responsive design with keyboard-safe layouts
- Waveform animation for audio
- Integrated state management with Bloc
- Video and audio playback with delete options
- Animated transitions and UI consistency

## Brownie Points
- Pixel-perfect UI from Figma
- Advanced animations (card scaling, transitions)
- Responsive layout on all devices
- State management with Bloc
- Optional: Used Dio for API calls (if you did)
